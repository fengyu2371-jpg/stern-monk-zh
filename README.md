# stern-monk-zh-tw v27｜城下町店鋪貼文與備份下載版

這是修士 Bot 的 Railway 部署精簡版。

## 部署檔案

```text
main.py
requirements.txt
railway.toml
data/
  faq_zh_tw.json
  tutorials_zh_tw.json
  dialogue.json
```

部署時請整包上傳，不要只留下舊版 `main.py`。

## 指令

```text
/學生資料
/今日穿搭推薦
/下載目前備份
/修士狀態
```

`/下載目前備份` 僅提供擁有「管理伺服器」權限的管理員使用。

## v27 新增功能

### 1. 店鋪論壇貼文綁定

在「我的地點」選擇地點後，新增：

```text
🔗 綁定／更新店鋪貼文
⛓️‍💥 解除店鋪連結
🏪 前往店鋪
```

玩家操作：

1. 在城下町論壇頻道自行建立店鋪貼文。
2. 在要作為封面的圖片訊息按右鍵，選擇「複製訊息連結」。
3. 回到 `/學生資料` → 我的地點 → 選擇地點。
4. 按「綁定／更新店鋪貼文」，貼上連結。

綁定條件：

- 必須是目前伺服器內的論壇貼文。
- 必須由操作玩家本人建立。
- 修士必須擁有查看論壇、讀取訊息紀錄的權限。

管理頁與公開城下町卡片會讀取綁定訊息中的第一張圖片；玩家修改圖片後，可再次按「綁定／更新店鋪貼文」選擇新的封面訊息。

### 2. 公開城下町入口

已綁定店鋪貼文的公開地點，在「商店街」翻頁畫面會顯示：

```text
🏪 前往店鋪
```

按下後會直接前往玩家的 Discord 論壇貼文。

### 3. 下載目前備份

管理員使用：

```text
/下載目前備份
```

修士會：

1. 使用 SQLite Backup API 建立目前資料庫的安全快照。
2. 壓縮為 ZIP。
3. 以私密訊息附檔傳送給管理員。
4. 傳送完成後刪除 Railway 暫存檔。

## 資料庫更新

本版會自動替 `student_places` 新增：

```text
shop_guild_id
shop_thread_id
shop_cover_message_id
```

既有學生、地點與神諭資料不會被清除，也不需要手動執行 SQL。

## Railway 權限提醒

修士在城下町論壇頻道至少需要：

```text
查看頻道
讀取訊息歷史
在討論串中查看內容
```

若 Bot 看不到論壇貼文，綁定時會顯示錯誤，不會破壞原地點資料。
