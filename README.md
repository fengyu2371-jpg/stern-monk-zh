# stern-monk-zh-tw v29.2｜工坊、料理與精神力版

這是修士 Bot 的 Railway 部署包。本版以原有 v28.2 城下町、學籍、店鋪與神諭功能為基底，新增獨立的城下町生活職業系統。

## 部署檔案

```text
main.py
town_life.py
requirements.txt
railway.toml
data/
  dialogue.json
assets/
  districts/
    town-overview.webp
    riverside-market.webp
    central-square.webp
    muggle-life.webp
    artisan-street.webp
    magic-commercial.webp
    old-town.webp
    academy-avenue.webp
  town_life/
    farm.webp
    ranch.webp
    fishing.webp
    mining.webp
    stove.webp
    items/
      *.png
```

部署時請完整上傳整個資料夾。不要只替換 `main.py`，否則會缺少 `town_life.py` 與城下町圖片。

部署前建議先使用 `/下載目前備份` 取得目前資料庫快照。

## 入口

玩家現在可以直接輸入：

```text
/城下町
```

指令會直接開啟生活職業主頁，顯示農牧師、漁採師、魔晶礦師、工坊總覽與背包。

原本入口仍然保留：

```text
/學生資料
→ 城下町
→ 生活職業
```

同一位玩家重新輸入 `/學生資料` 或 `/城下町` 時，Bot 會在新面板建立成功後，立刻把上一張面板切換成「舊面板已鎖定」並移除所有操作元件，只留下最新面板可操作。若新面板建立失敗，舊面板不會被誤鎖。

v11 起，玩家面板不再使用只能由短效互動權杖修改的斜線指令 Webhook 回覆，而是由 Bot 在頻道內建立一般訊息。面板因此可以在 5 分鐘後、開啟新面板時或 Railway 重新啟動後，繼續用 Bot 身分可靠鎖定。鎖定不需要「管理訊息」；Bot 在使用頻道至少需要「查看頻道」、「傳送訊息」、「嵌入連結」與「附加檔案」，若在討論串內使用，另需「在討論串中傳送訊息」。

修士主面板也提供「今日穿搭」按鈕，與 `/今日穿搭推薦` 共用每日一次限制。面板內完成推薦後可直接返回主面板；逾時或已被新面板取代的穿搭表單不會扣除使用次數。

### 手機版生活操作顏色圖標

釣魚、採集與採礦的批次按鈕會以顏色優先顯示操作量：

- 綠色：1 次
- 藍色：3 次
- 黃色：5 次
- 紅色：10 次
- 紫色：最多消耗 100 體力

## 三條職業路線

三條路線不會永久綁定，玩家可以同時培養。

### 1. 農牧師

- 購買與升級農具組。
- 三塊固定農田。
- 購買小麥、胡蘿蔔、月光草種子。
- 播種時自動填滿空地，成熟後一次收成。
- 農具等級越高，收成數量越多，播種體力消耗也會下降。
- 可飼養雞與牛。
- 雞需要農具組 Lv.1；牛需要農具組 Lv.2。
- 動物每天消耗飼料，採收雞蛋或牛奶。

作物成熟時間：

```text
小麥：15 分鐘
胡蘿蔔：30 分鐘
月光草：60 分鐘
```

### 2. 漁採師

- 購買與升級釣具組。
- 河岸釣魚會取得河魚、銀鱗鯉、月光鱒或泡水舊靴。
- 釣具等級越高，稀有魚獲機率越高，體力消耗越低。
- 野外採集不需要工具，可取得野莓、野生藥草與硬木枝。
- 沒有工具的新玩家也能先靠採集累積麻瓜幣。

### 3. 魔晶礦師

- 購買與升級挖礦工具。
- 可採得石材、銅礦與鐵礦。
- 挖礦工具 Lv.2 起，可能發現魔法水晶原礦。
- 魔晶礦師 Lv.2 起，可使用：

```text
魔法水晶原礦 ×2
鐵礦 ×1
```

精煉成：

```text
精煉魔法水晶 ×1
```

## 工具與經濟

玩家初始擁有：

```text
600 麻瓜幣
1000／1000 體力
```

第一級工具價格：

```text
農具組：180 麻瓜幣
釣具組：220 麻瓜幣
挖礦工具：260 麻瓜幣
```

每項工具最高 Lv.5。玩家可在河岸市集出售農牧、漁採與礦晶物資，也可以一次出售全部可售物資。種子與飼料不會被出售。

## 體力

- 體力上限 1000。
- 以台北時間計算，每天凌晨 00:00 重置為 1000／1000。
- 同一天每經過完整 1 分鐘自然恢復 1 點體力。
- 自然恢復與跨日重置會在玩家開啟城下町頁面或進行操作時一次結算，不需要背景排程。
- 體力達到上限後不會繼續囤積尚未使用的恢復時間。

## 信箱與維護補償

- 生活職業首頁可進入「信箱」，查看待領與已領取信件。
- 每封信以固定 `mail_key` 記錄，重啟 Bot 不會重複發放。
- 領取附件與標記已領取使用同一筆資料庫交易；失敗時全部 rollback。
- 本次維護會向部署當下已有城下町資料的玩家各發放「維護補償體力藥水」×1。
- 維護補償體力藥水恢復 250 體力，不可購買或出售。

## 高級礦坑分區

進入魔晶礦師頁面後，可直接選擇以下礦區：

- 外圍礦道：挖礦工具 Lv.1、魔晶礦師 Lv.1；以石材與銅礦為主。
- 深層鐵脈：挖礦工具 Lv.2、魔晶礦師 Lv.2；提高鐵礦比例並開始掉落水晶原礦。
- 魔晶洞窟：挖礦工具 Lv.4、魔晶礦師 Lv.3；水晶原礦機率最高、體力消耗也最高。

工具高於礦區最低門檻時，會略微降低該次採礦的體力消耗；高等工具也可能增加單次礦物數量。

## v29.2 工坊、精神力與料理

### 各區工坊

- 農田與畜牧場可進入「農牧工坊」。
- 河岸可進入「河岸工坊」。
- 高級礦坑可進入「礦坑工坊」。
- 生活職業主頁也保留「工坊總覽」，方便直接前往任一工坊。
- Lv.1 基礎工具只消耗麻瓜幣；Lv.2 以上會另外消耗石材、木枝、銅礦、鐵礦或魔晶素材。

### 精神力

- 新玩家精神力為 100／100。
- 精神力不會在凌晨與體力一起重置，可透過料理與每天最多兩次休息恢復。
- 目前工具升級、挖礦與魔晶精煉會消耗精神力；農牧、採集與釣魚的精神力消耗維持現行設定 0。
- 精神力不足時，該次行動不會扣除物資或體力。

### 料理

灶台目前提供 12 道料理：炭烤河魚、胡蘿蔔濃湯、農家早餐、
香煎月光鱒、野莓果盤、烤胡蘿蔔、水煮蛋、小麥麵包、野菜湯、
牛奶燉蛋、香煎銀鱗鯉與月光鱒套餐。

完成的料理會放入背包；玩家可在工坊或背包使用料理選單食用。
料理會依配方恢復體力與精神力，且不可直接出售。

### 麻瓜幣

玩家畫面與錯誤提示中的「金幣」已統一改名為「麻瓜幣」。SQLite 內部欄位仍保留 `coins`，因此不需要轉移或重建舊玩家餘額。

### 舊資料庫遷移

啟動新版時會安全檢查 `town_life_players`，若舊資料庫沒有以下欄位，程式會自動新增：

```text
spirit
max_spirit
```

既有玩家的工具、物資、麻瓜幣、職業經驗與體力資料不會被清除。


- 背包選取料理後可直接按「食用一份」恢復精神力。

## 批次生活職業操作

- 釣魚與採集可一次執行 1、5 或 10 次。
- 挖礦可依礦區一次執行 1、3 或 5 次。
- 各行動另有「100 體」快捷操作，單次最多消耗 100 體力。
- 掉落、數量、經驗與工具加成仍逐次計算，最後合併顯示。
- 體力或精神力不足時，只執行當下負擔得起的次數。
- 整批操作使用同一筆資料庫交易；中途失敗時，體力、精神力、物品與經驗全部 rollback。
